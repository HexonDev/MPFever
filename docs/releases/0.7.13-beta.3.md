Adds **Settings → Your settings → Check for beta releases**.

- Unchecked by default: automatic update checks consider stable releases only.
- Tick it to include beta/prerelease releases. The choice is saved locally and survives updates.
- Changing the setting refreshes the update check when automatic updates are enabled, and clears cached update candidates.
- Unticking it prevents a previously found beta from being installed.
- Version ordering now handles numbered betas correctly (`beta.10` follows `beta.2`); stable releases supersede their betas.

**Install this package manually once** if upgrading from beta.1/beta.2: those launchers do not have the checkbox and ignore prereleases.
Close MPFever and extract the entire ZIP. All players in a session should use the same MPFever version.

Includes the beta.2 startup fix: normal game launch works with `MPFEVER_IPC_PROBE` unset.
The .NET 10 Windows x64 runtime is bundled. The native pipe experiment remains off by default; gameplay still uses file IPC.
Application/native binaries are unsigned.

Downloads: `MPFever-0.7.13-beta.3.zip` for players, `MPFever-0.7.13-beta.3-server.zip` for dedicated servers,
and `MPFever-ServerList-0.7.13-beta.3.zip` for the standalone .NET Framework 4.8 list service.
SHA-256 hashes are provided in `SHA256SUMS-0.7.13-beta.3.txt`.
