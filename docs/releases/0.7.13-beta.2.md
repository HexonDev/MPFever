Fixes the game-start crash in **0.7.13-beta.1**:

> The given key 'MPFEVER_IPC_PROBE' was not present in the dictionary.

The optional environment switch is now read safely. Normal game launch works without setting any environment variables;
`0` keeps the pipe probe disabled and `1` enables it. Regression checks exercise the actual game-launch setup in both
the unset and disabled cases, in addition to the existing pipe protocol tests.

- **Players:** download `MPFever-0.7.13-beta.2.zip`.
- **Dedicated server:** download `MPFever-0.7.13-beta.2-server.zip`.
- **Server-list service:** `MPFever-ServerList-0.7.13-beta.2.zip` (.NET Framework 4.8).
- SHA-256 hashes are included in `SHA256SUMS-0.7.13-beta.2.txt`.

Close MPFever and extract the **whole package**. The player/server packages include the .NET 10 Windows x64 runtime.
Use the same MPFever version on all players in a session.

All other beta.1 changes remain: Lua polling optimizations, independent local testing, and the opt-in native pipe probe.
The pipe probe remains disabled by default; ordinary multiplayer uses file IPC. The probe's game-build and shutdown
limitations are unchanged. Application/native binaries are unsigned. This is an experimental prerelease.
